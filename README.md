**PYTHON-QUIZ-GAME** 

*ABOUT THE PROJECT*:-
The Python Quiz Game is a beginner-level project developed to practise python programming concepts. It presents multiple-choose questions,checks the users answers ,and displays the final score.

*FEATURES*:-
Multiple-choice quiz questions
Options labelled A,B,C,and D
checks whether the selected answer is correct
caluclates and displays the final score 

*PYTHON CONCEPTS USED*:-
*  Variables-Used (score) and (answer) to store values.
*  Strings-Used text for questions,options,and messages.
*  Output using print()-Displayed questions,options,feedback,and the final score.
*  Input using input()-Accepted the user's answer.
*  String method ( upper() )-Converted the user's answer to uppercase.
*  Functions-- created ask_question and start_quiz() to organise the program.
*  Functions parameters and arguments--passed questions,options,and correct answers to ask_question().
*  Conditional statements (if-else)-checked whether user answer was correct.
*  Return values-Returned 1 for correct answer and Returned 0 for wrong answer.
*  Arithmetic operators(+,==) used to compare and caluclate answers and score.
*  \n-Escape Character used to add the newlines,to improve the outputs readability.
